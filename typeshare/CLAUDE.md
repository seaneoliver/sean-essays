# Typeshare: Atomic Essays

Single-idea essays from https://typeshare.co/seanoliver, ingested in
chronological order (oldest first). Each folder is `NN-slug/` with `article.md`,
a section-level `CLAUDE.md`, and an `images/` subfolder.

Index will populate as each essay is ingested via the
[`add-essay-to-repo`](../.claude/skills/add-essay-to-repo/SKILL.md) skill.

Typeshare's profile page is a streaming Next.js app. Enumerating the full essay
list requires a one-time headless browser pass. See the project plan at
`~/.claude/plans/i-want-to-save-quizzical-pie.md` for that step.
